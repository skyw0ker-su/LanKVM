# LanKVM

Одна клавиатура и мышь на несколько компьютеров с Windows и Linux по локальной сети. Подвели курсор к краю экрана: он ушёл на соседний компьютер, и всё, что вы печатаете, попадает туда.

## Скачать (версия 0.1.0)

Все файлы — на странице релиза: https://github.com/skyw0ker-su/LanKVM/releases/tag/v0.1.0

- **Windows 10/11:** `LanKVM-0.1.0-Setup.exe` — установщик; `LanKVM-portable.zip` — без установки, распаковать и запустить `LanKVM.exe`.
- **Linux (Astra Linux, Ubuntu, Debian, Mint, X11):** `lankvm_0.1.0-1_all.deb`:

  ```
  sudo apt install ./lankvm_0.1.0-1_all.deb
  ```

  Команда `lankvm` запускает клиент, значок появляется в трее.
